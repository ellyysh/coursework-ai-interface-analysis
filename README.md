# Анализ визуальной перегруженности интерфейсов с использованием мультимодальной модели Qwen2.5-VL и LoRA

## О проекте

Данный проект посвящен дообучению мультимодальной языковой модели Qwen2.5-VL-7B-Instruct для задачи анализа визуальной перегруженности веб-интерфейсов. Модель способна анализировать скриншоты сайтов, выявлять признаки визуальной перегруженности и давать конкретные измеримые рекомендации по улучшению дизайна.

## Технологии

- Базовая модель: Qwen2.5-VL-7B-Instruct
- Метод дообучения: LoRA с 4-битным квантованием (QLoRA)
- Параметры LoRA: ранг 64, альфа 128, dropout 0.1
- Фреймворки: PyTorch, Transformers, PEFT, bitsandbytes
- Веб-интерфейс: Flask

## Установка и запуск

1. Клонирование репозитория:
   git clone https://github.com/ellyysh/coursework-ai-interface-analysis.git
   cd coursework-ai-interface-analysis

2. Установка зависимостей:
   pip install -r requirements.txt

3. Загрузка весов LoRA-адаптеров

4. Запуск веб-сервиса:
   python app/app.py
   После запуска откройте в браузере адрес http://localhost:5000

## Использование

1. Загрузите скриншот веб-страницы
2. Нажмите кнопку Анализировать
3. Модель вернёт анализ с перечнем проблем и рекомендациями

## Пример ответа модели

Анализ показал умеренную визуальную перегруженность страницы.

Основные проблемы:
1. В верхней части страницы меню содержит 12 пунктов, что превышает рекомендуемый предел в 7±2 элемента.
2. На главном баннере использовано 5 различных шрифтов и 4 акцентных цвета.
3. Карточки товаров расположены без достаточных отступов.

Рекомендации:
1. Сократить главное меню до 5-6 пунктов.
2. Привести оформление баннера к единой цветовой гамме с одним акцентным цветом.
3. Увеличить отступы между карточками до 20-24 пикселей.
